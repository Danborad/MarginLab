# 留白集 MarginLab

> 极简图片AI调色风格化与艺术拼图排版工具

自托管的 Web 版图片创作工作台：AI 调色修图、AI 风格化、艺术拼图排版、相册成书，以及米家相纸冲印导出。
界面走极简留白路线（白底、小圆角、克制留白），面向手机与桌面浏览器。

仓库地址：<https://github.com/Danborad/MarginLab>

## 功能

| 模块 | 说明 |
| --- | --- |
| AI 修图 | 上传照片 → 选风格 → 生成，按住对比原图，生成历史可反复调出，支持图库换图 / 本地上传 |
| 风格化 | 内置修图风格提示词库（按类别分栏），缩略图悬浮可看大图与提示词 |
| 创作工作台 | 内置生图模型，提示词与结果左右排布，同一聊天多轮生成只算一条历史 |
| 拼图 | 自由画布拼贴、图层 / 文字 / 相纸 / 形状贴纸、按图数（1–6 张）分组的自动排版模板 |
| 相册 | 素材与生成图的文件浏览器，可一键送进画布、设为参考图或下载 |
| 冲印导出 | 相纸尺寸（米家 6 寸 100×148mm / 3 寸 50×76mm）、完整不裁切 / 填满相纸、300–600 DPI，服务端重编码成标准冲印 JPEG |

## 技术栈

- 前端：React 19 + TypeScript + Vite 6 + Zustand + Tailwind CSS + Konva
- 后端：Node.js + Express 5（`server.js`），SQLite / JSON 落盘 + 本地文件系统
- 图片处理：ImageMagick（缩略图、冲印 JPEG 重编码）
- 部署：单进程自托管，默认双栈监听（`HOST=::`），前端构建产物由 Express 直接托管

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（前端热更新）
npm run dev

# 构建前端
npm run build

# 启动服务（默认 3001 端口，双栈）
npm start
```

常用环境变量：

```bash
HOST=::        # 默认 IPv6 + IPv4 双栈监听
PORT=3001      # 服务端口
```

启动后访问：

- 局域网：`http://<你的内网 IP>:3001/`
- 本机：`http://localhost:3001/`
- IPv6 字面量地址需要用方括号，例如 `http://[::1]:3001/`

首次使用由管理员账号完成初始化，之后可在管理员后台开启开放注册；AI 模型地址与密钥在后台「全局 AI 模型配置」里填写，落盘在 `server_data/ai_config.json`（不在版本库内）。

## 目录结构

```
├── src/                 # 前端源码（components / store / lib / types）
├── public/              # 站点静态资源（封面、风格缩略图、样张）
├── server.js            # Express 服务端：接口、持久化、缩略图与冲印导出
├── index.html           # 页面外壳（品牌与站点标题）
├── AGENTS.md            # 产品约定与设计决策记录
└── COLLAGE_PLAN.md      # 早期产品方案与技术选型
```

## 数据与隐私

- 用户数据、上传素材、AI 历史与缩略图缓存都写在 `server_data/`，**不进入版本库**；请自行备份该目录。
- 用户 JSON 里不存 base64 原图：素材落盘为文件，列表统一走缩略图接口 `/api/thumb`。
